# ⚖️ Академія правознавства: «Норма права. Структура норми права»

Інтерактивний навчальний веб-тренажер з правознавства для учнів 10 класу

## 📚 Навчальні блоки та ігрові механіки

Тренажер складається з 5 послідовних блоків, кожен із яких має власну інтерактивну механіку:

1. **Блок 1. Система права** — з'єднання понять лініями, побудова сходинок ієрархії елементів системи права та двокрові картки визначення галузі і поділу на публічне/приватне право.
2. **Блок 2. Джерела права** — встановлення відповідності та визначення джерела права за фрагментами нормативних актів і судової практики (з печаткою засвідчення).
3. **Блок 3. Види норм права** — класифікація норм за п'ятьма критеріями та комплексний комбінаторний аналіз.
4. **Блок 4. Структура норми права** — пошук гіпотези, диспозиції та санкції за допомогою «рентгену» норми та визначення їхніх типів із використанням інтерактивного довідника.
5. **Блок 5. Підсумковий** — комплексний фаховий аналіз правових норм за всіма вивченими критеріями.

## 🏆 Система відзнак

* **Академічні звання** — за проходження кожного блоку та почесне звання **«Майстер правознавства»** за успішність від 75%.
* **Значки майстерності** — за серії правильних відповідей поспіль, швидкість та безпомилкове проходження блоків.
* **Гербові печатки Феміди** — бронзова, срібна та золота відзнаки за загальну точність відповідей.
